259 /* Projection of a simple volume ------------------------------------------- */
260 // The projection is not precleaned (set to 0) before projecting and its
261 // angles are supposed to be already written (and all Euler matrices
262 // precalculated
263 // The projection plane is supposed to pass through the Universal coordinate
264 // origin
265 
266 /* Time measures ...........................................................
267  This function has been optimized in time, several approaches have been
268  tried and here are the improvements in time
269  Case: Base (unit time measure)
270  The points within the footprint are calculated inside the
271  inner loop instead of computing the foot coordinate for the
272  first corner and knowing the sampling rate in the oversampled
273  image go on the next points. The image access was done directly
274  (physical access).
275 
276  Notation simplification:
277  Case: VOLVOXEL(V,k,i,j) ----> V(k,i,j): + 38% (Inacceptable)
278  Case: DIRECT_IMGPIXEL ----> IMGPIXEL: + 5% (Acceptable)
279 
280  Algorithmic changes:
281  Case: project each basis position ----> +325% (Inacceptable)
282  get rid of all beginZ, beginY, prjX, ... and project each
283  basis position onto the projection plane
284  Case: footprint coordinates outside ----> - 33% (Great!!)
285  the footprint coordinates are computed outside the inner
286  loop, but you have to use the sampling rate instead to
287  move over the oversampled image.
288 */
